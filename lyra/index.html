About

All of Evolution X's features, kept calm and tuned device by device.

Lyra is named after the small constellation that holds Vega, one of the brightest stars in the night sky. Lyra stays close to Evolution X and fixes each device where Android 17 broke it.

Install

Before you start

  • An unlocked bootloader. On Xiaomi phones this is done with the official Mi Unlock tool, which erases the phone.
  • Android platform-tools (adb and fastboot) on your computer.
  • A backup of everything on the phone. The first install formats it.

Download (lisa)

From the latest build's folder on SourceForge (each build has its own dated folder), get the four files and check them against the .sha256 files next to them:

Lyra-1.0-lisa-20261104-1541.zip
Lyra-1.0-lisa-20261104-1541-boot.img
Lyra-1.0-lisa-20261104-1541-vendor_boot.img
Lyra-1.0-lisa-20261104-1541-dtbo.img

The three images are Lyra's recovery. It trusts Lyra's signing key, so the install runs without a signature warning.

First install

  1. Reboot to the bootloader and flash Lyra's recovery: 
    adb reboot bootloader
fastboot flash boot        Lyra-1.0-lisa-20261104-1541-boot.img
fastboot flash vendor_boot Lyra-1.0-lisa-20261104-1541-vendor_boot.img
fastboot flash dtbo        Lyra-1.0-lisa-20261104-1541-dtbo.img
fastboot reboot recovery
  2. In Lyra recovery choose Factory reset → Format data and confirm.
  3. Choose Apply update → Apply from ADB, then on the computer: 
    adb sideload Lyra-1.0-lisa-20261104-1541.zip
  4. When it asks to reboot to recovery, choose No, then Reboot system now. The first boot takes a few minutes.

Updates

New builds appear in Settings → System → Updater. Download, install, reboot. You can also sideload an update from Lyra recovery (adb reboot recovery, then Apply from ADB) without formatting.

Updating keeps your data. Only the first install, coming from another ROM, needs a format.
